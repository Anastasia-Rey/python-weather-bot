# 🌤 Telegram Weather Bot

Мой первый телеграм-бот, который показывает погоду в любом городе!

## 🛠 Технологии:
* Python 3
* Aiogram (для телеграм-бота)
* Python-Weather (для получения данных о погоде)

## 🚀 Как запустить:
1. Установите зависимости: `pip install aiogram python-weather`
2. Вставьте свой токен от BotFather в переменную `BOT_TOKEN`
3. Запустите файл: `python tgbot.py`
